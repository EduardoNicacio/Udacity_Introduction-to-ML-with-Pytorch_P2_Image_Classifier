# Working Locally

For this project, you can either complete the work on your own local computer or you can complete it within a workspace right here in the Udacity classroom. If you're going to use the workspace, you can skip the rest of this page.

## Task List (packages)

If you're going to be working on your own machine, make sure you have everything listed below. If you've been following along during the course, you may already have all of these set up, but it's good to check.

- [ ] Python version 3.6 or higher. You can find [instructions for downloading and installing Python here](https://www.python.org/downloads/).
- [ ] Pytorch version 1.4 or higher. You can install the current version of pytorch by running `pip install torch` in the command line.
- [ ] Torchvision version 0.8 or higher. You can install the current version of torchvision by running `pip install torchvision` in the command line.
- [ ] Numpy version 1.16 or higher. You can install the current version of numpy by running `pip install numpy` in the command line.
- [ ] Matplotlib version 3.0 or higher. You can install the current version of matplotlib by running `pip install matplotlib` in the command line.

## Task List (Notebook)

As you saw in the video earlier, we've created a starter notebook for you to work with—so the first step will be to download the notebook and get it running in your local Jupyter environment. You'll then complete the entire project within this notebook and, once it is ready, zip it up and submit it for review.

- [ ] [Click here to download a zip file containing the Jupyter notebook](https://video.udacity-data.com/topher/2021/January/600087a6_cifar-10-image-classifier-starter/cifar-10-image-classifier-starter.zip)
- [ ] Unzip the notebook and place it in a convenient location.
- [ ] From the command line, navigate to the notebook's location and run `jupyter` foloowed by the name of the notebook (as in `jupyter CIFAR-10_Image_Classifier-STARTER.ipynb`). This should launch the Jupyter environment in your browser, with the notebook available.
- [ ] Open the notebook and complete the cells as indicated.
- [ ] When you're ready to submit your notebook, zip it up and go to the submission page at the very end of this lesson.
